## The entry

> I sold at a loss to 'cut my losses'; the coin pumped 40% an hour later, and my group chat has renamed me 'Exit Liquidity.'

A setup, a turn, and a payoff a trader would repeat to a friend: sell at a loss,
watch it pump an hour later, and earn a new name in the group chat.

## How it works

`main.py` writes that single line to `/output/entry.txt` and nothing else.
It validates the line against the competition gate first (UTF-8, 1–200
characters, single line, no leading or trailing white space).

```sh
python3 main.py                 # writes /output/entry.txt
python3 main.py --self-test     # validates the entry against the gate
```
